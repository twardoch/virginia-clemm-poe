# [DeepSeek-V4-OSL](https://poe.com/DeepSeek-V4-OSL){ .md-button .md-button--primary }

## Bot Information

**Creator:** @OpenSourceLab

**Description:** Based on DeepSeek-V4-Flash an MIT-licensed open-weights model. This multimodal bot can process PDF, PNG, JPG, HEIC, TXT, HTML, DOCX, XLSX, CSS and PY files. This bot can't process RTF, WEBM, MP4 and MP3. Maximum file size is 50 MB. Users can adjust the temperature and verbosity of the responses in the settings. Context window: 1M tokens

Previous version: https://poe.com/DeepSeek-v3.2-OSL

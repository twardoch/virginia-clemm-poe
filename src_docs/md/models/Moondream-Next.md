## Bot Information

**Creator:** @fal

**Description:** Moondream-Next can describe images, detect objects or points in images, and detect a person's gaze in a photo. Pass in an image, a prompt to describe the task (for example, "detect all circles in this image", "caption this image") and specify the task to be performed with --task \[task_name\] (task_name ought to be one of `caption`, `bbox_detection`, `point_detection`, `gaze_detection`)

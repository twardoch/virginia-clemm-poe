**Description:** NVIDIA Nemotron 3.5 Super VL is an open-weight multimodal model designed for visual reasoning and long-running AI agents. It combines text, image, document, and video understanding with agentic reasoning and tool use in one model, preserving task-relevant visual context throughout specialized workflows. Built on a 120B parameter Mixture-of-Experts architecture with 12B active, it pairs a hybrid Mamba-Transformer design and multi-token prediction with NVFP4 KV cache quantization for efficient, concurrent long-context serving. This model can be customized through post-training on an organization's own data, tools, and policies for the highest accuracy on specialized multimodal agent tasks. Within a system of models, NVIDIA Nemotron 3.5 Super VL serves as the high-accuracy multimodal model, alongside Nemotron 3.5 Lightning for high-volume text and Nemotron 3 Ultra for the hardest text-only reasoning.

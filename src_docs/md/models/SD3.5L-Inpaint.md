# [SD3.5L-Inpaint](https://poe.com/SD3.5L-Inpaint){ .md-button .md-button--primary }

## Bot Information

**Creator:** @fal

**Description:** Inpainting bot based on the Stable Diffusion 3.5 Large model. Given an image and a mask (separate images), fills in the region of the image given by the mask as per the prompt. The base image should be the first image attached and the black-and-white mask should be the second image; a text prompt is required and should specify what you want the model to inpaint in the white area of the mask.

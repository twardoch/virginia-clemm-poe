## Bot Information

**Creator:** OpenSourceLab

**Description:** Trellis-3D is an open-source AI model designed to generate high-quality 3D assets from text or image prompts. It is fully open-sourced under the MIT license and developed by the Microsoft Research team. This bot generates 3D assets with textures and colors in GLB format, when you provide it a reference image. The generated model appears in a 3D canvas preview, where you can rotate, zoom, and inspect geometry in real time. This makes the tool ideal for rapid prototyping, learning 3D geometry, debugging OBJ files, and creating lightweight 3D assets.
